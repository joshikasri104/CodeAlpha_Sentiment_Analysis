# Sentiment Analysis on Amazon Reviews

## Objective
To analyze Amazon customer reviews and classify them into Positive, Negative, and Neutral sentiments.

## Tools Used
- Python
- Pandas
- TextBlob
- Matplotlib

## Steps Performed
1. Loaded Amazon Reviews dataset.
2. Performed sentiment analysis using TextBlob.
3. Classified reviews into Positive, Negative, and Neutral categories.
4. Visualized sentiment distribution using a bar chart.
5. Exported the results to a CSV file.

## Conclusion
The analysis showed that most customer reviews were positive, indicating overall customer satisfaction.
